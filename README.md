# Huntly — Job Hunt Buddy for College Students

A landing page prototype for Huntly, a job search tool designed specifically for college students.

## Problem
College students struggle to find jobs that are realistic to apply for and actually match their interests and experience level.

## Solution
Huntly filters job opportunities based on individual preferences — major, field, experience level, salary range, location, and job type — so every result is worth applying to.

## Features
- **Smart preference filters** — field, job type, salary, location, experience level
- **Match scoring** — each listing is scored against your profile
- **Deadline tracking** — surface time-sensitive listings before they close
- **Student-focused** — free for all college students

## Prototype
`index.html` — fully interactive landing page prototype with:
- Animated hero section
- Live filter sidebar (toggle chips, drag salary slider)
- Dynamic job card results
- Waitlist signup modal

## Stack
Plain HTML/CSS/JS — no build tools, no dependencies (except Google Fonts).

## To run locally
Just open `index.html` in a browser.
